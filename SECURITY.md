# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Use GitHub's private
[vulnerability reporting](https://github.com/akifkeklik/jeweler-pro/security/advisories/new)
instead. You will get an answer within a few days.

Please include the affected endpoint or screen, the steps to reproduce, and the impact
(for example: data of another business visible, or amounts changeable).

## Scope and design

The security design (sessions, tokens, tenant isolation, audit trail, data minimisation)
is documented in [backend/SECURITY.md](backend/SECURITY.md).
